# MONIAC

Интерактивная симуляция **MONIAC**, гидравлического компьютера Билла Филлипса (1949). Это кейнсианская модель экономики, где деньги текут как вода: уровень в баке — это запас, поток — это расход.

Сервер на **FastAPI** решает дифференциальные уравнения модели и 30 раз в секунду передаёт состояние по **WebSocket**. Клиент — одна HTML-страница, которая рисует анимацию на `<canvas>` и отправляет на сервер параметры с ползунков.

## Возможности

- Анимированная схема машины: насос, бак дохода, баки государства и частного сектора, нижний резервуар совокупного спроса, потоки налогов, сбережений, потребления, импорта и экспорта.
- Денежный рынок, как у Филлипса: процентную ставку задаёт уровень в баке свободных денег. Его можно выключить и задавать ставку вручную.
- Сразу видно текущий доход Y, равновесие Y*, мультипликатор, все потоки, сальдо бюджета, ставку.
- Пауза и сброс симуляции.
- Светлая и тёмная тема (по системной настройке), дизайн в стиле Apple.
- Русский и английский интерфейс: язык определяется по браузеру и запоминается.

## Модель

### Круговорот дохода

Насос поднимает воду в верхний бак: это **национальный доход Y**. Дальше поток делится:

| Поток | Формула | Куда уходит |
|---|---|---|
| Налоги | T = t · Y | бак «Государство» |
| Располагаемый доход | Yd = Y − T | |
| Потребление | C = c · Yd | |
| Импорт | M = m · C | из страны |
| Отечественное потребление | Cd = C − M | нижний резервуар |
| Сбережения | S = Yd − C | бак «Сбережения» |

**Утечки** (T, S, M) выводят деньги из оборота. **Инъекции** (G, I, X) вливаются в нижний резервуар независимо от текущего дохода. Насос качает пропорционально уровню в нижнем резервуаре (Y = 3 · h), поэтому система сама приходит к равновесию, где утечки равны инъекциям:

```
T + S + M = G + I + X
```

Равновесный доход:

```
Y* = k · (G + I + X),     k = 1 / (1 − c·(1 − t)·(1 − m))
```

При параметрах по умолчанию k ≈ 2,19: из каждого рубля дохода в оборот возвращается около 54 копеек.

### Баки государства и частного сектора

Баки копят разницу между утечкой и инъекцией и могут уходить в минус:

- **Государство** копит T − G: выше нуля профицит, ниже нуля госдолг.
- **Сбережения** копят S − I: выше нуля богатство частного сектора, ниже нуля его займы.

Вместе с торговым балансом они всегда подчиняются тождеству секторальных балансов:

```
(T − G) + (S − I) = X − M
```

### Денежный рынок

Если денежный рынок включён, ставка r не задаётся ползунком, а определяется так:

1. Часть денежной массы Mˢ занята в сделках: L₁ = 0,5 · Y.
2. Остальное — **свободные деньги**: idle = Mˢ − 0,5 · Y. Они плавно перетекают в отдельный бак.
3. Уровень бака через поплавок задаёт ставку: r = 12 − 0,4 · idle, в пределах от 0 до 12 %.
4. Ставка управляет клапаном инвестиций: I = I₀ · (1 − r / 15).

Модель находит совместное равновесие товарного и денежного рынков (IS–LM), и на ней видны два классических эффекта:

- **Эффект вытеснения.** Рост госрасходов поднимает доход, свободных денег становится меньше, ставка растёт и сокращает инвестиции. При G = 15 → 25 доход растёт на 13,8 вместо 21,9.
- **Ловушка ликвидности.** При денежной массе от ~80 ставка упирается в ноль, и дальнейшая эмиссия на доход не влияет. В ловушке госрасходы снова работают с полным мультипликатором.

Если денежный рынок выключен, ставка задаётся вручную и модель ведёт себя как простая кейнсианская.

### Параметры

| Параметр | Обозначение | По умолчанию | Диапазон |
|---|---|---|---|
| Склонность к потреблению | c | 0,80 | 0,50–0,95 |
| Ставка налога | t | 0,20 | 0–0,50 |
| Склонность к импорту | m | 0,15 | 0–0,50 |
| Госрасходы | G | 15 | 0–45 |
| Автономные инвестиции | I₀ | 20 | 0–45 |
| Экспорт | X | 10 | 0–45 |
| Денежная масса (рынок включён) | Mˢ | 60 | 0–150 |
| Процентная ставка (рынок выключен) | r | 5 % | 0–14 % |

Константы модели (коэффициент насоса, параметры спроса на деньги и инвестиций) заданы в начале `main.py`.

### Ограничения

Это учебная модель с фиксированными ценами:

- нет инфляции, поэтому номинальная и реальная ставки совпадают;
- нет потенциального выпуска: доход может расти без ограничений;
- нет валютного курса и движения капитала;
- нет центробанка, реагирующего на инфляцию.

## Архитектура

```
браузер (static/index.html)              сервер (main.py)
┌──────────────────────────┐   params   ┌──────────────────────────┐
│ ползунки, переключатели  │ ─────────▶ │ Params (pydantic)        │
│                          │   reset    │                          │
│                          │   pause    │ step(): метод Эйлера,    │
│ canvas-анимация          │ ◀───────── │ 2 подшага на кадр, 30 FPS│
│ показатели               │   state    │ equilibrium(): Y*, r*    │
└──────────────────────────┘            └──────────────────────────┘
```

У каждого WebSocket-подключения своё независимое состояние.

### Протокол `/ws`

Клиент → сервер:

```jsonc
{"type": "params", "data": {"c": 0.8, "t": 0.2, "m": 0.15, "G": 15, "I0": 20,
                            "X": 10, "Ms": 60, "mm": true, "r": 5}}
{"type": "reset"}
{"type": "pause", "value": true}
```

Сервер → клиент, примерно каждые 33 мс:

```jsonc
{
  "type": "state",
  "Y": 84.4, "r": 4.88, "tSec": 12.3,
  "hGov": 31.2, "hSav": 1.4, "hSump": 28.1, "hIdle": 17.8,
  "flows": {"T": 16.9, "S": 13.5, "C": 54.0, "Cd": 45.9,
            "M": 8.1, "Gout": 15, "Iout": 13.5, "X": 10},
  "params": { ... },
  "multiplier": 2.19,
  "yStar": 84.4,
  "rStar": 4.88
}
```
